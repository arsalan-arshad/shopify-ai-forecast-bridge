Architecture Overview

Shopify Ecosystem: shopify-ai-forecast-app calculates Weighted Moving Average (WMA) daily velocities and days-of-cover.
Bridge Gateway: Node.js Express server validates cryptographic HMAC-SHA256 signatures.
Salesforce CRM: Apex REST receiver upserts Shopify_Inventory_Snapshot__c and spawns urgent Task records when days_of_cover ≤ lead_time.
